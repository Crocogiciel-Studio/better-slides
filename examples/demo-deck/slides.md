# Demo deck

A small deck to review with comments.

---

# Why review with comments

Comments let you point at an element instead of describing where it is.

- Select an element in the preview
- Write a short note
- Send the whole stack at once

---

# Install

Run the demo from the project root.

```bash
pnpm install
pnpm demo
```

---

# Wrap up

The agent edits `slides.md` and the preview updates on its own.

1. Comment
2. Send
3. Review the result
