# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's "Report a vulnerability" button (Security tab of this repository), or by e-mail to guillaume.monrolin@crocogiciel.com.

Include what you found, how to reproduce it, and the version affected. We aim to acknowledge a report within 7 days.

## Scope notes

Better Slide runs locally and drives the AI CLIs already installed and logged in on the user's machine. It must never read, copy, store or transmit the CLI credentials or tokens. Any path that does so is a vulnerability.
