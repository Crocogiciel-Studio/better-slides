# VCS

## Platform

- Platform: GitHub, repository `Crocogiciel-Studio/better-slides`, reached with the `gh` CLI.

## Branches

- `main` is protected and holds everything. Work happens on short branches named `<type>/<short-description>`, such as `feat/comment-stack`.

## Commits

- Conventional commits: `<type>(<scope>): description`.
- Never add a `Co-Authored-By` trailer.

## Pull requests

- A pull request targets `main` and is merged by rebase, so history stays linear.
- The maintainer can bypass the protection, but a pull request is the default path.
